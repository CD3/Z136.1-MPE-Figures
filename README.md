# Z136.1 MPE Figures

Repository for the Gnuplot scripts used to create the MPE related figures (Figures 3a - 13) in the Z136.1 Safe Use of Lasers Standard.

This is a fork of https://github.com/bjlund314/Z136.1_Figures created to make changes for the next version of the standard. Original scripts
were written by Brian J. Lund in 2018-2023 and have been edited by CD Clark III


## Updates

### Build System

The original scripts uses a simple build system based on make/Makefiles. This build system has been replaced with Bash scripts. The decision to switch
to Bash was based on the need/desire to add new output image formats. The original scripts supported EPS and PDF. Support for PNG has been added
and the logic required to handle the differences between formats is (slightly) easier to write in Bash.

### Data

The original scripts used static data files. Some data was embedded directly into the Gnuplot scripts "here document" style, some were
standalone text files. There were a few scripts and even an Excel spreadsheet that seemed to be used to generate some of the data,
but most of the data was not generated by code.

This makes checking that the figures are correct more difficult because you have to redo the calculation by hand and compare the result
to the value in the data file. It also made updates based on changes to the MPE more difficult because, again, you would have to recalculate
all of the data file values by hand using the new MPE definition.

Currently, all of the Gnuplot scripts load data from text files (no more here documents).
All data files, even the small simplest ones, are not generated with Python scripts that live in the repository. These scripts are automatically
ran to generate the data files by the scripts used to run the Gnuplot scripts to generate data. The data files are also stored in the repository.
This makes it easier to see what changes have been introduced with tools like diff and git.
Most Python script currently just write the same static data that the original
scripts used right now, only a few actually calculate values with code. We will be porting all scripts to compute values from code.


### Refactor/Regression Tools

The repository contains some tools for detecting changes to the figures. This is done by running the current scripts, generating
EPS and PDF versions of all figures, and comparing them to a previous "golden" snapshot. This is useful for developing/refactoring/fixing
the Gnuplot scripts. For example, when the Figure 8 script was being updated to fix the major/minor tic marks, the
`scripts/compare.sh` script was used to detect any changes that were introduced and catch errrors.
